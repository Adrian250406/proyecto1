# 🍽️ Sistema Gastronómico y de Reservas "El Buen Sabor"

> **Plataforma Web Integral de Gestión de Restaurante, Carta Digital y Reservas en Línea**  
> Desarrollado con **Laravel 11.x (PHP 8.2+)**, **MySQL (XAMPP)**, arquitectura **MVC**, diseño **Glassmorphism** y **API RESTful**.

---

## 🚀 Inicio Rápido en 3 Pasos

```powershell
# 1. Instalar dependencias de PHP y Frontend
composer install
npm install

# 2. Configurar el entorno y generar la clave
Copy-Item .env.example .env
php artisan key:generate

# 3. Ejecutar las migraciones y levantar el servidor
php artisan migrate
php artisan serve
```

Acceder en el navegador: **`http://127.0.0.1:8000`**
